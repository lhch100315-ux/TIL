# setState와 ValueNotifier

## 1. setState()

Flutter의 `StatefulWidget`에서 상태를 관리하는 가장 기본적인 메커니즘이다.

상태가 변경되었음을 Flutter 프레임워크에 알려 위젯을 다시 빌드하도록 한다.

---

## 2. setState의 주요 특징

### ① 간단함
- 사용하기 쉽고 직관적이다.

### ② 지역성
- 해당 위젯의 상태만 관리한다.

### ③ 위젯 재빌드
- `setState()`가 호출되면 위젯의 `build()` 메서드가 다시 호출된다.

### ④ 동기적 작동
- Flutter의 다음 프레임에서 UI 업데이트가 발생한다.

---

## 3. setState 사용 시 주의사항

### ① 적절한 위치에서 호출
- 위젯의 라이프사이클 메서드에서 적절히 호출해야 한다.

### ② 빌드 중 호출 금지
- `build()` 메서드 내에서 `setState()`를 호출하면 무한 루프가 발생할 수 있다.

### ③ 최적화
- 필요한 상태 변경만 수행하여 불필요한 재빌드를 방지한다.

---

## 4. setState의 한계

### ① 위젯 트리에서의 전파
- 부모와 자식 관계가 깊어질수록 상태 전달이 번거롭다.

### ② 상태 공유
- 서로 다른 위젯 간에 상태를 공유하기 어렵다.

### ③ 비즈니스 로직 분리
- UI와 비즈니스 로직을 명확하게 분리하기 어렵다.

### ④ 코드 중복
- 유사한 상태 로직이 여러 위젯에 중복될 수 있다.

---

# 5. ValueNotifier와 ValueListenableBuilder

## ValueNotifier

- 값의 변경을 감지하고 리스너에게 알릴 수 있는 Flutter의 내장 클래스이다.
- `setState()`보다 좀 더 유연한 상태 관리를 제공한다.
- `StatelessWidget` 내에서도 사용할 수 있다.

---

## 6. ValueNotifier의 주요 특징

### ① 위젯 독립성
- `StatelessWidget`에서도 사용할 수 있다.

### ② 세분화된 업데이트
- 전체 위젯이 아닌 필요한 부분만 업데이트할 수 있다.

### ③ 명시적 구독
- `ValueListenableBuilder`를 통해 변경 사항을 명시적으로 구독할 수 있다.

### ④ 단일 값 관리
- 각각의 `ValueNotifier`는 하나의 값을 관리한다.

---

# 7. setState 사용이 적합한 경우

### ① 단순한 UI 상태
- 간단한 위젯 내부 상태를 관리할 때

### ② 지역적 상태
- 단일 위젯 내에서만 사용되는 상태를 관리할 때

### ③ 일시적 상태
- 위젯의 생명주기와 함께하는 일시적인 상태를 관리할 때

---

# 8. ValueNotifier 사용이 적합한 경우

### ① 위젯 간 상태 공유
- 여러 위젯이 공통 상태에 접근해야 할 때

### ② 세분화된 UI 업데이트
- 위젯의 특정 부분만 업데이트하고 싶을 때

### ③ StatelessWidget 내 상태
- 상태를 가진 `StatelessWidget`을 구현할 때

### ④ 복잡한 상태 로직
- 상태 로직을 UI 코드에서 분리하고 싶을 때

---

# 9. setState의 성능 특징

### 위젯 전체 재빌드
- `setState()`가 호출되면 해당 `StatefulWidget`의 `build()` 메서드 전체가 실행된다.

### 필요한 최적화
- `const` 생성자 사용
- 위젯 분리

등을 통해 재빌드 범위를 최소화할 필요가 있다.

---

# 10. ValueNotifier의 성능 특징

### ① 부분 업데이트
- `ValueListenableBuilder`를 사용하면 UI의 필요한 부분만 업데이트할 수 있다.

### ② 세밀한 제어
- 여러 상태를 각각의 `ValueNotifier`로 분리하여 독립적으로 관리할 수 있다.

---

# 11. setState vs ValueNotifier

| 구분 | setState | ValueNotifier |
|---|---|---|
| 기본 사용 대상 | `StatefulWidget` | 위젯과 독립적으로 사용 가능 |
| 상태 관리 범위 | 지역적 상태 | 특정 값 중심의 상태 |
| UI 업데이트 | `build()` 전체 재실행 | 필요한 부분을 중심으로 업데이트 |
| 상태 공유 | 상대적으로 어려움 | 여러 위젯에서 활용 가능 |
| 사용 난이도 | 간단함 | 비교적 유연함 |
| 적합한 경우 | 간단한 위젯 내부 상태 | 세분화된 상태 관리 |
